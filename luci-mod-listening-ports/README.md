# LuCI App for Network Ports Status

This mini-app shows the IP addresses and ports that the router is listening on. 

# Install

```bash
apk add --allow-untrusted luci-mod-listening-ports-1.0-r4.apk
apk add --allow-untrusted luci-i18n-listening-ports-ru-1.0-r4.apk
```
or
```bash
opkg install luci-mod-listening-ports-1.0-r4.apk
opkg install luci-i18n-listening-ports-ru-1.0-r4.apk
```
